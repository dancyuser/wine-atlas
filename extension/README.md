# Wine Atlas Evidence Capture (Chrome / Chromium / Edge)

Локальное расширение Manifest V3 для ручного документированного сбора данных с **активной вкладки**. Предназначено для страниц, которые сам пользователь может законно открыть и просмотреть в обычном браузере. Не обходит CAPTCHA, антибот-защиту, авторизацию, paywall, `robots.txt` или HTTP 403, не читает сетевой трафик и не делает запросов к сайтам в фоне.

## Установка

1. Скачайте архив репозитория [Wine Atlas](https://github.com/dancyuser/wine-atlas/archive/refs/heads/main.zip) и распакуйте.
2. Откройте `chrome://extensions` (Chrome) или `edge://extensions` (Edge), включите режим разработчика.
3. Нажмите **Загрузить распакованное расширение / Load unpacked**, укажите каталог `extension`.
4. Закрепите значок Wine Atlas Capture.

## Сбор недостающих данных

1. Откройте расширение, загрузите файл `data/wines.json` из репозитория.
2. Выберите вино. Список указывает отсутствующие поля. Нажмите **Открыть карточку**.
3. На странице конкретной бутылки (в открытой пользователем вкладке) откройте расширение и нажмите **Снять текущую вкладку**.
4. Сверьте URL, название вина, винтаж и объём. Если любое из четырёх условий не подтверждено, расширение не разрешит сохранить наблюдение. Данные с рекомендованных товаров, с другой страницы или другого винтажа нельзя подтверждать. Если сайт показывает CAPTCHA или другой товар, снимок не сохраняйте.
5. Поставьте флажок подтверждения и нажмите **Сохранить наблюдение**.
6. Повторите для остальных вин. Наблюдения сохраняются **только в локальном хранилище браузера**. Нажмите **Скачать проверяемый JSON**.
7. В рабочей копии репозитория выполните:

   ```bash
   python scripts/import_manual_capture.py ~/Downloads/wine-atlas-manual-2026-11-23.json
   python scripts/import_manual_capture.py ~/Downloads/wine-atlas-manual-2026-11-23.json --apply
   python scripts/validate_catalog.py
   python scripts/validate_enrichment.py
   python -m unittest discover -s scripts -p 'test_import_manual_capture.py' -v
   ```

   Первая команда - **dry-run**, сообщает, что будет принято/отклонено. Сохраните исходный JSON до применения.

## Какие данные импортируются

- Только значения, обозначенные явно на странице и подтверждённые пользователем: цвет, тело, потенциал хранения, стиль, вкус, аромат, гастрономические сочетания, крепость, производитель, регион. Результат записывается в `stores[].research_details` и дополняет отсутствующие поля `product_details`, **не изменяя исходный архивный снимок**.
- Цена и состояние наличия - только из **однозначного Product/Offer JSON-LD**, после строгой проверки адреса, года и объёма и ранее подтверждённой принадлежности к каталогу. Цена записывается отдельно в `stores[].live_offer`; исторические цены остаются прежними.
- Перед обновлением импортёр повторно проверяет URL, год, объём и подтверждение пользователя. Несовпадения не импортируются.
- Фото, рейтинги покупателей, внешние оценки критиков и цены до скидки **не импортируются автоматически**. Ссылки на изображения остаются кандидатами без прав на повторное использование.
- Для семи позиций без установленного года импорт отключён: название, винтаж и объём должны иметь однозначное подтверждение. Невинтажные вина требуют отдельной схемы идентификации, а не автоматически присвоенного года.

## Ограничения и защита данных

Расширение использует `activeTab`, `scripting`, `storage`; не содержит `host_permissions`, фонового сервис-воркера или сетевых запросов. Оно собирает только ограниченные видимые атрибуты продукта и отдельные поля структурированных Product/Offer данных. Оно не сохраняет cookies, токены, HTML целиком, тела HTTP-запросов, скрытые фреймы или картинки. Не включайте в JSON персональные данные.

**Не публикуйте архив `wine-atlas-background-snapshots-2026-11-23(1).zip` в GitHub:** исходный HTML может содержать данные сессии. Для полноценных импортов готовых снимков используйте проверенный офлайн-парсер, а не публичное хранение сырых страниц.

Успех установки расширения не означает возможности открыть сайт, если доступ уже запрещён сервером. Сбор производится только с страниц, реально доступных пользователю.
