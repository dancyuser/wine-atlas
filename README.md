# Мой список вин

Личный статический вишлист из Google Docs «Виш-лист (Алкоголь)». По состоянию на 22.11.2026 документ содержит единственную вкладку `Tab 1`. В каталоге **124 уникальных вина**: из 130 ссылок исключены три позиции джина и три повторных вхождения ссылок.

## Синхронизация

- [Актуальный Google Doc](https://docs.google.com/document/d/1LXx9i0LY90GCnJnrXbUxN1_UlhjnowtdVA1NOI7KLt4/edit)
- Дата синхронизации: 22.11.2026; ревизия Google Docs зафиксирована в `data/wines.json → source.revision_id`.
- Вина с числовой оценкой Vivino: **120** (71 - точный винтаж, 49 - общая оценка без подтверждённого года). Ещё четыре позиции имеют документированный статус отсутствия числовой оценки.
- Вкладка «Вина СПб — исследование», существовавшая ранее, сейчас в документе отсутствует. Сведения о 51 вине из прежней подборки (включая цены и рейтинги) сохранены в `data/archive/spb-research-2026-11-14.json`; 39 вин отсутствуют в нынешней вкладке и больше не отображаются на сайте. Оставшиеся 12 входят в актуальный вишлист, поэтому отображаются в нём.
- Цены, помеченные 14.11.2026, являются **архивными**, актуальное наличие не подтверждено.

## Возможности

Поиск, фильтрация по стране, сорту, виду вина и сочетаниям с едой; сортировка по рейтингу, цене и году; локальное избранное в `localStorage`. В карточках доступны оценки Vivino и критиков со ссылками на источники. Общий индекс - эвристическое среднее оценок конкретного винтажа, где Vivino условно приводится по формуле `50 + 10 × оценка Vivino`; это не официальное преобразование шкал.

Сайт не содержит оформления заказов и не собирает персональные данные. Юридический статус публичного размещения сведений о ценах и продавцах алкоголя требует отдельной оценки в свете ст. 21 Федерального закона № 38-ФЗ «О рекламе».

## Основные файлы

- `index.html`, `styles.css`, `app.js` - интерфейс сайта.
- `data/wines.json` - активный список вин и метаданные синхронизации Google Docs.
- `data/ratings.json` - рейтинги и статусы только активных вин.
- `data/archive/spb-research-2026-11-14.json` - прежняя подборка СПб с рейтингами и историческими ценами. Не включается в отображаемый каталог.
- `data/overrides.json` - уточнения названий для повторного импорта.
- `scripts/build_catalog.py` - локальный импорт `source.txt` из текущего списка; старый раздел исследования игнорируется. Совпавшие карточки сохраняют проверенные данные и архивные цены.
- `scripts/validate_catalog.py`, `scripts/validate_ratings.py` - проверки целостности.
- `scripts/update_prices.py`, `.github/workflows/refresh-prices.yml` - ручная проверка доступных публичных цен с соблюдением robots.txt.
- `.github/workflows/pages.yml` - публикация сайта при изменениях `main`.

## Локальный просмотр

```bash
python scripts/validate_catalog.py
python scripts/validate_ratings.py
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для нового текстового экспорта используйте `python scripts/build_catalog.py source.txt`; `source.txt` не публикуйте в GitHub.

При следующих обновлениях сверяйте структуру вкладок: если вкладка исследования восстановится, необходимо заново решить правила её включения в сайт.

## Качество названий

Названия нормализованы: артикулы, EAN, упаковочные объёмы и винтаж не включаются в заголовок карточки. Год и объём отображаются отдельно. Неизвестный сорт винограда не заменяется догадкой и не показывается в метаданных как «сорт не указан». Проверенные имена и точечные уточнения фиксируются в `data/overrides.json` и сохраняются при повторном импорте. Валидатор блокирует публикацию названий с пятизначными артикулами, суффиксами объёма и повтором года.

## Тема оформления

При первом открытии используется тёмная тема. В шапке сайта можно выбрать «Тёмная», «Светлая» или «Как в системе». Выбор сохраняется в `localStorage` под ключом `wine-atlas-theme`; системный режим отслеживает изменения `prefers-color-scheme`. Тема применяется до загрузки CSS, чтобы не возникала вспышка неправильного фона. Проверка `node scripts/test_theme.mjs` охватывает переключение, сохранение настроек и контрастность основных текстовых сочетаний.

## WineStyle: импорт подтверждённых карточек

По пользовательскому экспорту браузерной сессии от 22.11.2026 проверены 121 URL WineStyle. **118 карточек совпали с исходным товаром и годом**, три несовпадающих товарных варианта пропущены. В `data/wines.json` импортированы 118 явно показанных цен (включая отдельные статусы ожидания товара), 246 оценок, опубликованных продавцом (включая 64 восстановленные повторным анализом первичного экспорта), характеристики и описания 118 вин. Цены до скидки не подтверждены. Данные относятся к моменту наблюдения, **не являются гарантией актуального наличия или цены**.

Сведения, опубликованные WineStyle от имени Vivino и критиков, сохраняются отдельно в `stores[].product_details.ratings`, с исходной шкалой, источником, датой и текстовым подтверждением; они **не перезаписывают** independently verified `data/ratings.json` и не участвуют в расчётном индексе. Фильтры используют подтверждённые сорта винограда и группы гастрономических сочетаний с сохранением ручных уточнений.

Отчёт с исключёнными винтажами и SHA256 исходного пользовательского экспорта: [data/archive/winestyle-import-audit-2026-11-22.json](data/archive/winestyle-import-audit-2026-11-22.json). Исходный полный HTML-архив не публикуется в репозитории. Повторяемый импорт: `scripts/import_enrichment_overlay.py` (dry-run по умолчанию); проверки: `scripts/validate_enrichment.py`, `scripts/test_enrichment_import.py`, `scripts/test_enrichment_ui.cjs`.

Автономные обращения к WineStyle ранее возвращали HTTP 403; состояние блокировки сохраняется в `reports/winestyle-access.json`. Этот PR не отправлял новые сетевые запросы, полученная пользователем выгрузка проверялась **офлайн**. Подробности: [docs/winestyle-parser.md](docs/winestyle-parser.md).

## Доработка 23.11.2026

Из исходного пользовательского экспорта WineStyle восстановлены 64 пропущенные числовые оценки по 27 карточкам: теперь в каталоге 246 оценок продавца. `scripts/recover_capture_ratings.py` восстанавливает оценки из уже собранного JSON офлайн, проверяет SHA256 оригинального экспорта, каноническую ссылку, идентификатор и год вина. Идемпотентный режим по умолчанию - dry-run. Оценки магазина не являются независимо подтверждёнными оценками конкретного винтажа и не включаются в индекс.

Макет карточек уплотнён: длинные характеристики находятся в сворачиваемом блоке с переносом строк, оценки разных уровней достоверности разделены. Убрано растягивание соседних карточек на высоту самой длинной.

Для фотографий введено поле `photo` с точной привязкой к вину, году, URL изображения и странице источника. Проверены 7 фотографий из 124; оставшиеся 117 позиций показывают нейтральный силуэт вместо неверного изображения. Фото загружаются с исходных сайтов, их доступность и правовой режим внешнего использования не гарантируются. Перед широким публичным использованием фотографий необходима проверка прав.

### Проверка цен 23.11.2026

Повторная сверка исходного экспорта WineStyle от 22.11.2026 выявила 30 пропущенных цен в заголовках подтверждённых товаров. Ранее в каталоге было 88 датированных цен; теперь заполнены все 118 карточек, прошедших проверку идентичности. Три редиректа на другой вариант вина остаются исключёнными, ещё три ссылки отсутствовали в пользовательском захвате. **Цены не являются актуальными котировками на 23.11.2026:** это подтверждённый срез предыдущего дня, включая отдельные товары в ожидании поступления. Для воспроизводимости добавлена офлайн-утилита `scripts/recover_capture_prices.py`, которая сверяет SHA256 архива, URL, ID, винтаж и первичное расположение цены в тексте. Данные о цене до скидки по-прежнему отсутствуют. Проверено семь фотографий бутылок по точному вину и винтажу.

## Доступность и отображение рейтингов (23.11.2026)

Из пользовательского архива полных снимков Wine Atlas Background Collector v5.1 (124 URL) проверены 116 совпавших карточек. Наличие определено **только по основному товарному блоку** `.m-productpage-price`: кнопка «Добавить в корзину» означает возможность заказа; `.m-productpage-price__status = Ожидаем поступление` без кнопки - отсутствие в продаже. Восемь вин с подтверждённым отсутствием скрыты из публичного каталога, но сохранены в `data/wines.json` для последующего возврата при возобновлении продаж. 108 подтверждены доступными к заказу. У восьми оставшихся идентичность страницы не подтверждена: отсутствие товара **не выводится** из редиректа или невозможности проверки.

Надписи «Ожидаем поступление» вне основного товарного блока (например, в `.o-bottom-bar`) не считаются свидетельством отсутствия. В исходном парсере такие надписи ошибочно классифицировали четыре доступных вина.

На сайте исключены пользовательские рейтинги WineStyle, но восстановлены оценки профессиональных критиков, опубликованные продавцом; они учитываются в сводном рейтинге с отметкой о посреднике и неопределённости винтажа. Старые записи и исходный архив сохранены.

Дата проверки наличия - 23.11.2026; результат не является постоянной гарантией доступности. Реестр и диагностические сведения: `data/archive/inventory-audit-2026-11-23.json`.

## Данные архива и рейтинги (23.11.2026)

Снимки Wine Atlas Background Collector v5.1 восстановили 116 **точно идентифицированных** товарных предложений WineStyle. Повторно проверены исходные URL, соответствие карточке, HTML SHA-256, первичное предложение цены и основная галерея фото. Сжатый и проверяемый реестр в `data/verified-snapshot-2026-11-23.json` содержит 116 пар «цена + идентификатор фото»; 108 пар относятся к показываемым винам, ещё 8 - к винам, скрытым из-за отсутствия в продаже. Связь с исходными страницами сохраняется в `wines.json` по идентификатору вина и URL продавца.

На сайте эти цены помечены как **архив на 23.11.2026**, а не как текущие. Фото подгружаются с CDN WineStyle по адресам основной галереи; если CDN заблокирует внешнюю загрузку, применяется ранее подтверждённый URL фото, затем заглушка. Самих файлов фотографий в репозитории нет, права на изображения не проверялись.

**Уточнение рейтингов:** исключены только пользовательские рейтинги самого WineStyle. Оценки, выставленные Wine Enthusiast, James Suckling, Decanter, Robert Parker, Jancis Robinson и другими профессиональными критиками и опубликованные WineStyle, **отображаются** отдельно от независимо полученных. Их оригинальный год урожая и источник оригинальной публикации не всегда установлены, поэтому они помечены соответствующим предупреждением. Из 246 отображённых ранее баллов WineStyle 33 относятся к Vivino, а 213 к названным критикам. Vivino, полученные только от продавца, не подставляются вместо самостоятельно проверенной оценки.

**Сводный рейтинг** учитывает отдельно собранные оценки и оценки критиков из WineStyle, убирая дубликаты по имени критика и отдавая приоритет непосредственно подтверждённым источникам конкретного винтажа. Шкала 20 приводится к 100 множителем 5, Vivino - эвристически по формуле 50 + 10 × оценка Vivino. Сводный рейтинг не следует считать оценкой конкретного винтажа без проверки области каждой исходной оценки.

Дополнительно по первоисточникам подтверждены пять оценок конкретных винтажей: Dow's LBV 2018 (Wine Enthusiast 93), Kopke LBV 2018 (Wine Enthusiast 92), Kendall-Jackson Chardonnay 2018 (Wine Enthusiast 90), Braida Vigna Senza Nome 2023 (Wine Enthusiast 94 и Falstaff 92). Эти баллы записаны в `data/ratings.json`.

Для 8 видимых вин вне подтверждённого архива собраны отдельные внешние URL изображений с указанием источников (их доступность для прямой загрузки и лицензии пока не гарантированы). **6 цен** и **4 независимо подтверждённых числовых Vivino** остаются не заполнены. Ложную точность из редиректов и рекомендательных блоков парсер не создаёт.

Повторный офлайн-разбор нового полного HTML-архива:
```bash
python scripts/ingest_full_snapshots.py wine-atlas-background-snapshots-2026-11-23.zip --date 2026-11-23
python scripts/ingest_full_snapshots.py wine-atlas-background-snapshots-2026-11-23.zip --date 2026-11-23 --output data/verified-snapshot-2026-11-23.json
python scripts/validate_verified_snapshot.py
python scripts/report_catalog_gaps.py --output gaps.json
```
Первый вызов выводит отчёт без записи. Для страниц со сменой URL, другим годом, неустановленной идентичностью либо без подтверждённой цены/фотографии сохраняется причина отказа.

Интерфейс оформлен в стиле редакционного винного каталога Burgundy Archive, с тёмной и светлой темами, увеличенной галереей бутылок, адаптивной сеткой и более явной иерархией цен и источников.
