# Wine Atlas: экспериментальный браузерный сбор исследования

Расширение собирает видимые данные с сайтов и сохраняет их локально. Python обрабатывает выгрузку и добавляет подтверждённые записи в каталог.

1. В Chrome откройте `chrome://extensions`, включите режим разработчика и загрузите распакованную папку `research-extension`.
2. Нажмите значок расширения, затем «Собрать оценки критиков» для первой фазы или «Собрать все источники» для совместного обхода. Предоставьте доступ к выбранным сайтам.
3. Очередь сначала обходит критиков, затем магазины в неактивных вкладках. Окно расширения можно закрыть. На каждом сайте обход ограничен тремя страницами каталога и десятью карточками на страницу. Для магазинов приоритет у ссылок, похожих на уже собранные названия. Прогресс хранится локально, браузер подхватывает очередь после перезапуска.
4. При блокировке или авторизации адрес получает статус `blocked`, а очередь переходит к другим страницам. После разрешённого пользователем получения доступа можно запустить сбор заново. По завершении браузер скачивает JSON; его также можно скачать кнопкой.
5. Для сводки выполните `python scripts/report_research_capture.py путь-к-файлу.json`. Для проверки совпадений и предложений запустите `python scripts/import_research.py путь-к-файлу.json --report research-report.json`. Команда с `--apply` добавляет подходящие записи в `data/discovered-wines.json`. Для повторной обработки сохранённого среза используйте `--rates` со снимком XML ЦБ того же дня. Для проверенных вручную вариантов написания можно передать `--aliases` с JSON вида `{"https://…": "Единое название"}`.

Выгрузка содержит адреса без параметров, заголовок, выбранные видимые фрагменты и найденные ссылки. Она может содержать текст закрытых страниц, которые вы открыли под своей учётной записью: проверяйте её до передачи кому-либо. Cookies, HTTP-заголовки и полный HTML не сохраняются.

Автоматический импорт использует структурированные наблюдения с поддерживаемых страниц Wine Enthusiast, Falstaff, Vinous, Sabonis, Vinissimo, WineStyle и Luding. Для Decanter, DWWA, IWSC, James Suckling и Jancis Robinson включён предварительный разбор явных числовых шкал. Остальные источники дают ссылки и фрагменты для проверки. Пагинация поддерживается при наличии ссылки на следующую страницу. Сайты, где список загружается кнопкой, за подпиской или через динамические фильтры, могут дать неполный результат. Статус `needs_review` описывает сбор фрагмента, до проверки импортером.

Первая фаза формирует очередь для точного поиска винтажей в магазинах. Архив первичных фактов и способ пересобрать очередь описаны в [отчёте по критикам](../docs/critic-stage-2026-11-24.md).

У Luding наличие у поставщика при явно выбранном городе Санкт-Петербург считается допустимым состоянием наличия для последующей проверки; этот статус должен сохраняться отдельно от наличия в конкретном магазине.
