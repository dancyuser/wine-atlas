Об источниках и оценках

Сортировка по рейтингу учитывает число уникальных источников N и размер выборки Vivino. Индекс = средний балл − 8 / √N − 6 × (1 − C) / N, где C = w × n / (n + 100), n — число оценок Vivino. Последнее слагаемое отсутствует, если Vivino нет. Вес w = 1 для точного винтажа, 0,6 для всех урожаев и 0,35 для общего числа оценок, если балл винтажа известен, а число его оценок нет. При неизвестном числе оценок C = 0. Сортировка Vivino использует балл − 0,6 × (1 − C). Сами исходные баллы и сводное среднее не меняются. Популярность не увеличивает число источников; рост выборки уменьшает штраф с насыщением. Это сравнительная эвристика, а не статистический доверительный интервал.

Сводный рейтинг - справочный средний балл по отдельно собранным оценкам и по оценкам профессиональных критиков, опубликованным продавцом WineStyle. Повторные оценки одного критика учитываются один раз; при наличии собственной проверки винтажа она имеет приоритет. Шкала 20 приводится умножением на 5, оценка Vivino - условно по формуле 50 + 10 × рейтинг. Такой расчёт служит ориентиром для вишлиста и не является рейтингом конкретного года урожая.

Отзывы покупателей WineStyle не используются. Оценки Wine Spectator, Wine Enthusiast, Decanter, James Suckling, Jancis Robinson и других критиков, опубликованные на WineStyle, показаны с указанием посредника; соответствие конкретному винтажу и первоисточники не подтверждены отдельно. Оценки Vivino без установленного винтажа помечены «все урожаи».

Если независимо полученного Vivino нет, может использоваться оценка Vivino, указанная на WineStyle, с явной пометкой об источнике и неподтверждённом винтаже. При расхождении приоритет имеет непосредственно проверенная карточка Vivino.
